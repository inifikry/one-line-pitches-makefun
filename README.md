# A Day of One-Line Pitches

One sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The sentence

> Describe the app idea you've been carrying around in plain words, and an AI agent on make.fun will build a real, working first version of it for you, no coding required and nothing to lose by trying.

The pitch speaks to the friend directly: the idea they have already been carrying around, described in plain words, turned into a real working first version by an AI agent, with no coding required and nothing to lose by trying. Plain language, one concrete reason to say yes now, and no overpromising.

## How it runs

`main.py` writes the exact sentence above to `/output/entry.txt` (creating `/output` if needed). No input, no network, no dependencies beyond the Python standard library.
